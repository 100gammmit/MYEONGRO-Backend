# 오늘의 운세 정적 콘텐츠 작성

## 작업 입력

- 카드별 해석 근거는 활성 카드 사전 `src/main/resources/prompts/tarot/arcana/major/major-arcana-ko-v4.md`에서 해당 카드 섹션만 읽어 사용하세요.
- 카드 사전에 없는 고전 덱의 그림, 인물 자세, 색, 소품, 동물이나 배경을 알고 있더라도 추가하지 마세요. 카드 근거는 사전에 적힌 추상 의미를 생활 언어로 풀어 쓰세요.
- Preview는 지정된 1~10장, 실사용 세트는 Major Arcana 22장을 대상으로 카드당 서로 다른 결과 6개를 작성하세요.
- OpenAI API나 다른 외부 생성 API를 호출하지 마세요.

## 안전하고 독립적인 해석

- 모든 문장은 자연스럽고 짧은 한국어 해요체로 쓰며 격식체를 섞지 마세요.
- 사용자에게 실제로 생긴 사건, 관계, 직업, 약속, 성취, 상처, 선택이나 소유물을 만들어내지 마세요.
- 카드 의미상 특정 상황을 언급해야 한다면 그 상황이 사용자에게 있다고 단정하지 말고 조건부로 표현하세요.
- 성공, 실패, 인정, 연락 같은 결과를 보장하지 말고 의료·법률·재정 결정이나 위험 행동을 권하지 마세요.
- 어느 필드에서도 사용자가 수행할 과제나 행동을 지시하지 마세요.

## 서로 다른 여섯 변형

- 카드와 자연스럽게 이어지는 일상적인 상태와 태도를 사용하세요.
- 비교적 편하게 풀리는 해석 2개, 장점과 주의점이 함께 있는 해석 2개, 지연이나 부담에 무게가 있는 해석 2개를 만드세요.
- 같은 상황이나 결론은 2개를 넘지 말고, 단어만 바꾼 결과를 별도 변형으로 세지 마세요.
- 카드와 관계없는 정리, 휴식, 안부, 산책, 물건 치우기로 변형 수를 채우지 마세요.

## 바로 이해되는 한국어

- 목적어나 뜻이 흐린 단어 결합, 보고서 문체, 뜻을 숨기는 시적인 압축을 피하세요.
- `흐름`, `리듬`, `속도`, `온도`, `여백`, `에너지`, `기준`, `방향` 같은 추상어만으로 결론을 대신하지 마세요. 필요하면 무엇이 어떻게 달라지는지 같은 문장 안에서 밝히세요.
- 여섯 변형의 어순과 연결 방식을 바꾸고, 같은 종결 표현을 반복하지 마세요.
- 카드 이름은 body에 정확히 한 번 쓰세요. `~처럼`, `~의 상징은`, `~의 모습은`을 기계적으로 반복하지 말고 장면과 해석을 자연스럽게 연결하세요.

## 필드 책임

- title은 핵심 인상을 자연스러운 구나 문장으로 쓰세요.
- heading은 title과 겹치지 않는 구체적인 상태나 인상을 짧은 서술형 문장으로 쓰세요. 행동을 제안하는 동사를 쓰지 마세요.
- body는 2~3개의 짧은 문장으로 오늘의 방향, 카드 근거, 주의점을 자연스럽게 연결하세요.
- guidance는 행동 지침이 아니라 리딩을 읽은 사람에게 직접 건네는 따뜻한 메시지입니다.
- guidance 배열에는 마침표로 끝나는 짧은 서술문 하나만 넣으세요. 두 문장을 이어 붙이지 마세요.
- guidance는 body의 의미를 벗어나지 않는 허용, 위로 또는 기대를 쉬운 말로 전하고, body에 없던 비유·대상·상황·해석을 추가하지 마세요.
- 긍정적인 해석에는 편안한 기대를, 혼재된 해석에는 한쪽으로 서둘러 결론 내리지 않아도 된다는 여유를, 어려운 해석에는 오늘의 어려움을 과장하지 않는 위로를 담으세요.
- guidance에서 행동을 권하거나 질문하지 말고, title·heading·body를 그대로 요약하지 마세요.
- 사람을 평가하거나 인생 전체로 범위를 넓히는 표현, 어느 카드에도 붙일 수 있는 상담 상투어, 같은 위로의 문장 틀 반복을 피하세요.
- disclaimer는 모든 항목에 정확히 `이 내용은 오락과 자기 성찰을 위한 것으로 전문적인 조언을 대신하지 않아요.`를 사용하세요.

## JSON 계약

결과는 설명이나 Markdown fence 없이 다음 객체의 JSON 배열만 작성하세요.

```json
[
  {
    "cardId": "major-00-fool",
    "variantIndex": 0,
    "title": "...",
    "today": {
      "heading": "...",
      "body": "..."
    },
    "guidance": ["..."],
    "disclaimer": "이 내용은 오락과 자기 성찰을 위한 것으로 전문적인 조언을 대신하지 않아요."
  }
]
```

- 카드마다 `variantIndex` 0~5를 정확히 한 번씩 사용하세요.
- Preview 파일에는 지정된 카드만, 실사용 파일에는 22장×6개인 132개만 포함하세요.
- 작성 후 `dailyCardContentValidate`로 검증하고 실패한 항목은 외부 API 호출 없이 직접 고쳐 다시 검증하세요.
