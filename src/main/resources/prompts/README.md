# 리딩 프롬프트 보존 정책

운영 리소스에는 현재 활성 파일과 각 용도의 직전 활성 파일만 보존한다. 직전은 파일명의 숫자가 아니라 활성 설정의 변경 이력으로 판단한다. 사주 common과 기본 해석 가이드는 일반·연간이 공유하며, 월운 보충 가이드는 연간에만 조합한다.

| 용도 | 현재 | 직전 보존 |
| --- | --- | --- |
| 공통 안전 | reading-safety-ko-v3 | v2 |
| 타로 common | common-ko-v165 | v107 |
| 타로 카드 사전 | major-arcana-ko-v4 | v3 |
| 고민 | mind-three-card-ko-v73 | v70 |
| 관계 | relationship-three-card-ko-v24 | v21 |
| 선택 | choice-five-card-ko-v20 | v18 |
| 사주 공통(일반·연간 공유) | common-ko-v25 | v16 |
| 사주 기본 해석(일반·연간 공유) | base-interpretation-ko-v8 | v2 |
| 연간 월운 해석 보충 | monthly-interpretation-ko-v1 | 이전 guide7에 포함 |

| 연간 사주 리포트 | annual-monthly-ko-v31 | v28 |

사주 프롬프트 경로는 모두 `application.yaml`의 `app.reading.prompts.saju`에서 설정한다. 카탈로그는 경로에 버전을 고정하지 않고 설정된 리소스를 조립한다. 이 표는 설정을 대체하지 않으며 활성 파일 변경 시 함께 갱신한다.

## 사주 역할과 합성

- 공통 common: 신뢰 경계, 편안한 존댓말, 공통 본문·요약 책임과 출력 원칙.
- 공유 기본 해석: 원국·연운의 계산 의미, 생활어 풀이와 불확실한 근거의 사용 범위.
- 연간 월운 보충: monthlyFlow와 연간 배경 전환의 의미. 일반에는 전달하지 않는다.
- 리포트: 각 section의 순서·길이·고유 해석 역할. 일반의 세부 표현 제한은 연간으로 확대하지 않는다.
- 일반 합성: common → 기본 해석 → 일반 리포트 → 공유 safety.
- 연간 합성: common → 기본 해석 → 월운 보충 → 연간 리포트 → 공유 safety.

새 이름의 가이드는 기존 guide5·guide7을 공유 기본과 연간 보충으로 재편한 것이다. 이전 조합을 복구할 수 있도록 두 구가이드를 보존하며, 현재 두 가이드를 중복 조합하지 않는다. 순서와 책임 이동은 모델 출력에 영향을 줄 수 있으므로 내용 중복 제거와 품질 무회귀를 같은 것으로 보지 않는다.

## 변경과 복구

- 이미 사용한 버전의 본문을 덮어쓰지 않고 새 버전을 추가한다.
- 새 조합 검증 후 현재 설정과 직전 보존 파일을 갱신한다. 더 오래된 버전은 Git 이력으로 복구할 수 있다. 미커밋 후보는 이력이 없으므로 제거하기 전에 로컬 보관한다.
- 개발 폴더의 `prompts/legacy/activated`와 `prompts/legacy/inactivated`는 저장소 밖의 로컬 보관소이며 런타임 참조 대상이 아니다. 새 checkout에는 함께 내려오지 않는다.
- 테스트만 사용하는 구버전은 `src/test/resources/prompts`에 고정 fixture로 둔다. 운영 리소스의 보존 개수를 늘리기 위해 남기지 않는다.
- 직전 리소스의 보존이 현재 Java·JSON 계약과의 롤백 호환성을 보장하지는 않는다. 특히 카드 parser나 guidance 계약이 바뀐 경우 코드·설정의 해당 Git 커밋을 함께 검토한다.
- 프롬프트 정리 때문에 파일명 기반 `prompt_version`이나 현재 생성 결과를 바꾸지 않는다.
- 활성 버전 변경과 구버전 정리를 서로 다른 브랜치에서 진행했다면 병합 후 보존 집합을 다시 확인한다. 공유 common 변경은 일반·연간 모두에 적용되므로 양쪽을 검증한다. 공유 이전으로 롤백할 때는 코드·설정을 함께 검토한다.
- 구버전 제거 전에 운영 설정·Java의 고정 리소스 참조·테스트 참조를 확인한다. 아직 테스트에서 필요한 리소스는 같은 classpath의 test 리소스로 옮기고, 없는 리소스 참조를 남기지 않는다.
