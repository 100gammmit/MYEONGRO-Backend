메이저 아르카나 카드 의미:
- major-00-fool / 바보: 새로운 시작, 자유, 순수한 가능성. 첫걸음과 가능성을 살피고 충동과 준비 부족을 점검한다.
- major-01-magician / 마법사: 의지, 창조, 실행력. 자원 집중과 실현, 의도 분산과 말-행동 불일치를 살핀다.
- major-02-high-priestess / 여사제: 직관, 내면, 숨은 지혜. 내면의 목소리와 불안·선입견을 구분한다.
- major-03-empress / 여제: 풍요, 돌봄, 성장. 돌봄과 성장, 지나친 희생과 자기돌봄을 살핀다.
- major-04-emperor / 황제: 질서, 책임, 안정. 기준과 책임, 통제와 완고함의 균형을 살핀다.
- major-05-hierophant / 교황: 전통, 배움, 신념. 검증된 조언과 낡은 관습의 재검토를 살핀다.
- major-06-lovers / 연인: 관계, 조화, 가치 선택. 진솔한 소통, 엇갈린 기대와 회피한 선택을 살핀다.
- major-07-chariot / 전차: 전진, 의지, 방향성. 추진력과 함께 속도보다 방향을 점검한다.
- major-08-strength / 힘: 용기, 인내, 부드러운 통제. 다정한 용기와 자신감 회복을 살핀다.
- major-09-hermit / 은둔자: 성찰, 탐구, 내면의 빛. 조용한 성찰과 과도한 고립을 구분한다.
- major-10-wheel-of-fortune / 운명의 수레바퀴: 변화, 순환, 전환점. 흐름 수용과 반복 패턴의 변화를 살핀다.
- major-11-justice / 정의: 균형, 진실, 책임. 공정한 판단과 편견·책임 회피를 점검한다.
- major-12-hanged-man / 매달린 사람: 멈춤, 관점 전환, 내려놓음. 관점 전환과 무의미한 희생을 구분한다.
- major-13-death / 죽음: 마무리, 변환, 재탄생. 정리와 새 단계, 변화에 대한 저항을 살핀다.
- major-14-temperance / 절제: 조화, 회복, 균형. 조율과 회복, 불균형의 조절을 살핀다.
- major-15-devil / 악마: 집착, 유혹, 그림자. 속박을 인식하고 해로운 습관에서 벗어날 여지를 살핀다.
- major-16-tower / 탑: 충격, 해체, 진실의 드러남. 불안정한 기반과 미뤄 온 수리를 차분히 살핀다.
- major-17-star / 별: 희망, 치유, 영감. 회복의 가능성과 낙담 속 작은 근거를 살핀다.
- major-18-moon / 달: 불확실성, 감수성, 무의식. 감정을 존중하면서 사실을 확인한다.
- major-19-sun / 태양: 활력, 성공, 명료함. 자신감과 현실적인 기쁨을 살핀다.
- major-20-judgement / 심판: 각성, 성찰, 새로운 부름. 과거 성찰 후 결정하고 과도한 자기비판을 완화한다.
- major-21-world / 세계: 완성, 통합, 성취. 완성과 통합, 남은 마무리를 살핀다.

이 MVP에서는 모든 카드가 정방향입니다. 저장되는 `reversed` 값은 항상 `false`입니다.
