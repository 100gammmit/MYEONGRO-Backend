# 국내 출생지 카탈로그

`kr-admin-v1.json`은 2026-08-05에 고정한 국내 출생지 좌표 원본이다.

- 행정구역 code와 명칭: 행정안전부 행정표준코드관리시스템의 `법정동코드 전체자료` 중 `폐지여부=존재`
- 대표 좌표: 행정안전부 공공데이터포털의 `지진재해대응시스템 행정구역정보_20240808`
- 대표 좌표 산출: 해당 시·군·구의 활성 읍·면·동 좌표 평균
- 서비스 입력은 시·도까지만 받으며, 계산에는 각 시·도에 속한 시·군·구 대표 좌표의 중앙값을 사용한다.
- 출생 시각 미상은 출생지를 받지 않고 대한민국 기준 경도 127.5도를 사용해 하루 전체 후보의 공통값만 남긴다.
- 좌표와 행정구역 세부 정보는 서버 계산에만 사용하며 OpenAI 입력과 공개 출생지 목록 응답에 포함하지 않는다.
- 2024 좌표 자료 이후 신설된 시·군·구: 최신 법정동 자손과 기존 활성 읍·면·동을 대응해 평균
- 공개 API 응답에는 좌표와 시·군·구를 노출하지 않고 시·도 code와 이름만 제공

- <https://www.data.go.kr/data/15039043/fileData.do>

행정구역 또는 좌표 자료를 갱신할 때 기존 파일을 덮어쓰지 않는다. 새 catalog version을 추가하고 계산 규칙의 golden fixture를 함께 검증한다.
